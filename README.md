# vudepchai2.github.io

Vic Lê's personal site, built by GitHub Pages with Jekyll.

## Write a blog post

1. Copy `_drafts/post-template.md` into `_posts/` and name it `YYYY-MM-DD-short-title.md`, for example `_posts/2026-11-30-why-agency.md`.
2. Change the `title` and `description` at the top, and write the post below in Markdown.
3. Commit and push to `main`. GitHub builds the site in about a minute.

The post appears at `/blog/short-title/`, on the blog page, and among the three latest posts on the home page. The site also publishes an RSS feed at `/feed.xml`.

Images go in `assets/img/` and are used as `![What the picture shows](/assets/img/name.jpg)`.

Drafts in `_drafts/` are never published.

## Files

- `index.html`: the home page.
- `blog/index.html`: the list of all posts.
- `_layouts/`: the shared page frame (`base.html`) and the post page (`post.html`).
- `assets/site.css`: all styles.
